# 执行文档

## 一、集成 SingleFile

### 1.1 安装 SingleFile CLI
```bash
npm install -g single-file-cli
```

### 1.2 创建 SingleFile 封装模块
- 文件: `singlefile_downloader.py`
- 功能: 调用 single-file 命令行工具下载网页
- 参数: URL、输出目录、额外选项

### 1.3 构建时处理
- 打包时包含 Node.js 运行时
- 或使用 npx 直接运行

---

## 二、新增文献下载工具

### 2.1 UI 布局
- 在主界面新增 Tab: "文献下载"
- 多行文本框输入多个 URL（每行一个）
- 下载按钮、进度显示

### 2.2 下载流程
1. 解析输入的 URL 列表
2. 逐个调用 SingleFile 下载
3. 下载完成后应用清理脚本

### 2.3 输出结构
```
downloads/
  文献收藏_20260215/
    文章标题1/
      index.html
    文章标题2/
      index.html
    ...
```

---

## 三、热更新脚本库

### 3.1 脚本存储
- 目录: `clean_scripts/`
- 格式: JSON 配置文件

### 3.2 脚本结构
```json
{
  "name": "知乎清理脚本",
  "domains": ["zhihu.com", "zhuanlan.zhihu.com"],
  "version": "1.0",
  "rules": {
    "remove_selectors": [".Modal", ".LoginContainer", ...],
    "remove_text_patterns": ["登录", "注册", ...]
  }
}
```

### 3.3 内置脚本
- `zhihu.json` - 知乎清理
- `csdn.json` - CSDN清理
- `general.json` - 通用清理

### 3.4 热更新机制
- 启动时检查脚本目录
- 可从远程加载新脚本（可选）

---

## 四、文献打包功能

### 4.1 打包结构
```
文献收藏包/
  index.html (导航页)
  articles/
    文章1/
      index.html
    文章2/
      index.html
  assets/
    (共享资源)
```

### 4.2 导航页功能
- 列表显示所有文章
- 鼠标滚轮切换
- 点击打开文章
- 搜索功能

### 4.3 打包为 EXE
- 生成独立的文献浏览器
- 内置所有文章和资源

## 六、资源管理改进

### 6.1 自动获取标题
- 从网页 `<title>` 获取
- 清理标题中的特殊字符
- 作为文件夹名称

### 6.2 简化路径
- 不再使用域名作为路径
- 直接使用标题作为文件夹名
